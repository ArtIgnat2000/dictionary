# Академия СЛОВО 2.0 — анализ текущей версии и план развития

**Фокус новой редакции:** ученик 2 класса, мобильный телефон, полная автономность (офлайн),
уровень вовлечения как у Duolingo. Начинаем с минимального работающего ядра и наращиваем.

Дата: 25.09.2026 · Автор: анализ выполнен по коду ветки `arena/01a0d767-dictionary`
(базируется на `gh-pages` @ `9c5a619`).

## Часть 1. Что уже есть (инвентаризация)

### Стек и сборка
| Слой | Решение | Комментарий |
|---|---|---|
| UI | React 19 + TypeScript, Vite 7 | собирается без ошибок (`tsc -b && vite build`) |
| Анимация | Framer Motion 12 | используется везде (11 файлов) |
| Состояние | Zustand 5 + persist → **localStorage** | `slovo-progress`, `slovo-settings` |
| Стиль | Tailwind v4 + свой `tokens.css` (iOS-glass) | тема светлая/тёмная/авто |
| Звук | Web Audio API (синтез тонов) | без файлов — хорошо |
| Речь | Web Speech API (`speechSynthesis`), ru-RU | риски — см. P0-4 |
| Иконки | `phosphor-react` (5 иконок в навигации) | дорого для 5 иконок |
| PWA | рукописный `sw.js` + `manifest.json` | см. P0-5 |
| Деплой | GitHub Actions → GitHub Pages, base `/dictionary/` | работает |
| Мёртвые зависимости | `howler`, `idb`, `react-router-dom` | **не используются нигде** |

Сборка: `dist/assets/index.js` = **510 kB (135 kB gzip)**, CSS 18.5 kB.
Слишком много для «дешёвого» мобильного интернета и старых Android, на которых и будут
запускать детское приложение.

### Данные
`src/data/words/gradeN.json`, всего **779 слов** по 11 классам. Формат слова:

```json
{ "id": "g2_01", "text": "алфавит", "hint": "буквы",
  "sentence": "Выучи русский ____.", "difficulty": 2 }
```

В 3–11 классах `hint` и `sentence` часто мусорные («словарное слово», «Напиши слово: ____»),
во 2 классе — качественные (30 слов). Это подтверждает: **новую редакцию строим вокруг
качественного контента 2 класса, а не вокруг всех 11 классов.**

### Сильные стороны текущей версии (что точно берём в v2)
1. **Кастомная русская раскладка** в приложении — системная клавиатура на телефоне съедает
   пол-экрана и перекрывает задание. Решение верное.
2. **Маскот БУК (сова)** — SVG с 6 эмоциями, перетаскивается, реагирует на успех/ошибку.
   Это ровно тот «baby-schema»-персонаж, на котором держится эмоциональная привязанность.
3. **Синтез звука в коде** (без файлов) — мгновенно, ноль веса, работает офлайн.
4. **SM-2** как основа интервального повторения — методологически правильно.
5. **PWA без регистрации и без сервера** — правильный выбор для школьного проекта:
   никаких персональных данных ребёнка, никаких аккаунтов.
6. iOS-стиль glass-дизайн, тёмная тема, safe-area, `100dvh` — мобильная вёрстка в целом сделана.

## Часть 2. Что мешает достичь цели (проблемы по приоритету)

### P0 — блокируют цель «как Duolingo»

**P0-1. Нет модели урока и навыка, есть только «сессия».**
`SessionEngine` просто берёт N слов из SRS-очереди, а тип игры выбирается по индексу:
`GAME_SEQUENCE[idx % 5]` (`src/components/Session/index.tsx:37`).
В Duolingo же фундамент — **дерево/путь навыков**: «Урок 1: Животные», уровни освоения
(короны 0→5), видимый путь вперёд и понятная «следующая цель». Сейчас ребёнок не видит ни
пути, ни прогресса по конкретному уроку, ни причины вернуться именно к этому уроку.

**P0-2. Слово ни разу не показывается целиком до того, как его спрашивают.**
Первое же задание на новом слове — диктант на слух («напиши слово, которого ты никогда не видел»).
Для *проверяемых* орфограмм это работает (можно подобрать проверочное слово), но **словарное
слово по определению нельзя вывести** — его можно только запомнить. Ребёнок угадывает,
ошибается, и в память может записаться ошибочный образ.
Методика требует цепочки **LOOK → SAY → COVER → WRITE → CHECK**
([Spelling Handbook](https://www.dyslexicadvantage.org/wp-content/uploads/2015/10/spelling-handbook.pdf));
исследования показывают, что чистого «-write-10-раз» мало, а извлечение из памяти работает
значимо лучше — но **только после этапа предъявления**
([Dymock & Nicholson; retrieval practice у второклассников, η² = .42–.64](https://www.researchgate.net/publication/321087057_To_what_extent_does_children's_spelling_improve_as_a_result_of_learning_words_with_the_look_say_cover_write_check_fix_strategy_compared_with_phonological_spelling_strategies)).

**P0-3. Ошибка не отрабатывается, а лишь фиксируется.**
При ошибке: звук «грустно», −20 к score, показ правильного слова, через 800 мс — следующее
слово. Нет ни «напиши правильно сейчас», ни разбора, где именно ошибка, ни возврата к этому
слову в конце урока. В методике это ключевой момент: **«заставь помигать опасную букву»,
записать слово 3–5 раз с проговариванием**
([Работа со словарными словами, Продлёнка](https://www.prodlenka.org/metodicheskie-razrabotki/22978-rabota-so-slovarnymi-slovami)).

**P0-4. Нет понятия «опасное место» (орфограммы) в модели данных.**
Сейчас `Word = {id, text, hint, sentence, difficulty}`. А ядро методики 2 класса — это
*ударение, деление на слоги, подсветка безударной/непроверяемой буквы, орфографическое
проговаривание, «окошко» вместо опасной буквы*
([nsportal, 2 класс](https://nsportal.ru/nachalnaya-shkola/materialy-mo/2016/02/24/rabota-so-slovarnymi-slovami-v-nachalnyh-klassah)).
Без этих полей в данных невозможно построить ни «умную» подсказку, ни правильный разбор ошибки.

**P0-5. Автономность не доказана.**
- В `public/` **отсутствуют** `icon-192.png` и `icon-512.png`, на которые ссылается `manifest.json`
  → установка на экран телефона покажет пустую иконку.
- `index.html` тянет **Google Fonts** снаружи → офлайн шрифт не загрузится (нужно либо
  системный шрифт, либо локальный файл).
- `sw.js` не делает precache app-shell: кеш наполняется только по факту обращений.
- Нет offline-fallback-страницы.
- iOS вытесняет кеш PWA примерно через **7 дней неактивности**
  ([PWA Mobile Testing Checklist 2026](https://mobileviewer.github.io/pwa-mobile-testing-checklist-2026))
  → нужен вызов `navigator.storage.persist()` + «тёплое» напоминание.
- Хранение в **localStorage** (5 МБ, синхронно, вытесняется первым). `idb` уже лежит в
  зависимостях, но не используется — для v2 источник истины должен быть IndexedDB
  ([Offline-first patterns](https://dev.to/zeeshanali0704/frontend-system-design-offline-support-and-progressive-web-apps-pwas-4k8m)).

**P0-6. Озвучивание (диктант) может просто не заработать.**
Web Speech API: на iOS `speak()` срабатывает **только внутри обработчика жеста пользователя**,
список голосов грузится асинхронно (`voiceschanged`), русского голоса может не быть без
загрузки в настройках, часть голосов — сетевые, Firefox Android не поддерживает синтез
([Speech Synthesis API: limitations](https://www.testmuai.com/learning-hub/speech-synthesis-api-browser-support/),
[Web Speech API vs Cloud](https://vocafuse.com/blog/web-speech-api-vs-cloud-apis/)).
А «Диктант» — главное упражнение для словарных слов. Нужен план Б.

### P1 — сильно влияют на вовлечение

**P1-1. Экономика наград никуда не ведёт.** Есть XP и кристаллы, но **не на что тратить**,
нет уровней профиля, нет ежедневной цели, нет «пятёрки заданий дня». В Duolingo именно
ежедневная цель + серия + видимая полоса прогресса дают возврат
([Duolingo UX Breakdown 2026](https://www.925studios.co/blog/duolingo-design-breakdown)).

**P1-2. Нет этапа «закрепление сюжета».** У текущей версии 5 миров и карта, но карта — это
список классов, а не приключение. Для второклассника нужен видимый маршрут с точками-уроками,
которые открываются один за другим.

**P1-3. Дублирование данных.** `GRADE_DATA` с импортом всех 11 JSON повторяется в 4 компонентах
(`Session`, `QuickStart`, `Dictionary`, `WorldMap`) → весь словарь попадает в главный бандл.
Нужен единый реестр контента и ленивая загрузка.

**P1-4. Вес бандла 510 kB.** Framer Motion + phosphor + react. Для детского приложения на
слабом Android и медленном интернете цель — ≤ 200 kB gzip на старте.

**P1-5. Сессия однообразна и «ровная».** Нет перемешивания по принципу интерливинга,
нет «неожиданного» бонуса, нет вариативности reward (в Duolingo — сундуки, двойной XP;
у детей работает предсказуемо-непредсказуемое поощрение
([геймификация детских приложений](https://digitaloxy.ru/ru/article/kak-gejmifikacziya-pomogaet-uderzhivat-detej-v-prilozhenii-i-uvelichivat-czennost-produkta/))).

### P2 — желательно

- **Нет родительского контура.** Для 7–8 лет родитель — это тот, кто открыл приложение и
  следит за серией. Нужен минимум: как занимался, где ошибки, экспорт/перенос прогресса.
- **Нет обратной связи по тактильности** — `navigator.vibrate` не используется, а для
  мобильной игры это половина ощущения «отклика».
- **Нет локальной диагностики**, где ребёнок спотыкается (какие буквы/слова/типы заданий).
  Без этого улучшать контент можно только на глаз.
- **Дизайн «взрослый»**: мелкий текст, iOS-эстетика. Для 2 класса нужно крупнее, ярче,
  меньше чтения, больше образов.

## Часть 3. Лучшие практики, на которые опираемся

### 3.1 Удержание (Duolingo и не только)
- **Короткий ежедневный цикл**: одно занятие = 3–5 минут; цель дня видна сразу.
- **Play first, profile second**: ребёнок играет в первый урок до всяких настроек
  ([925studios](https://www.925studios.co/blog/duolingo-design-breakdown)).
- **Серия дней + «заморозка серии»** — самый сильный механизм удержания; потерять серию
  страшнее, чем получить бонус (loss aversion)
  ([ludaxis](https://www.ludaxis.io/blog/gamification-in-apps-duolingo-case-study-2026)).
- **Маскот с «baby schema»** — большие глаза, округлость → эмоциональная привязанность.
- **Немедленная и вариативная обратная связь**: салют/звук/вибрация за успех,
  *мягкая* реакция на ошибку (без «буззера» и без насмешки)
  ([digitaloxy](https://digitaloxy.ru/ru/article/kak-gejmifikacziya-pomogaet-uderzhivat-detej-v-prilozhenii-i-uvelichivat-czennost-produkta/)).
- **Детям младше 8 лет противопоказан глобальный рейтинг/лиги** — только сравнение с собой
  и кооперация с родителем.
- **Ошибки проектирования**: 10 однотипных заданий подряд, линейный сценарий без выбора,
  «обучение на фоне игры» (когда игра — декорация к скучному заданию)
  ([Bang Bang Education, Kidstech](https://bangbangeducation.ru/point/ux-ui-dizain/kidstech/)).

### 3.2 Методика правописания (начальная школа)
Рабочая последовательность для словарного слова:
1. **Предъявление**: показать слово целиком + картинка/смысл + ударение + деление на слоги.
2. **Орфографическое проговаривание** (проговаривать «как пишется», а не как слышится).
3. **Опасное место**: подсветить букву, которую нужно запомнить; «окошко» вместо неё.
4. **Зрительный образ**: закрыть глаза, «увидеть» слово, «помигать» опасной буквой.
5. **Извлечение**: написать/собрать без подсказки — это и есть проверка.
6. **Разбор ошибки**: показать, *какая именно* буква не та, и сразу переписать верно.
7. **Мнемоника** для самых трудных слов (короткие рифмовки, «слово-помощник»).
Тематические блоки по 5–10 слов, один блок в неделю — проверенная школьная практика.

### 3.3 Техника для офлайн-PWA
- App-shell precache + версионирование кешей + удаление старых кешей на `activate`.
- IndexedDB = источник истины для прогресса; localStorage — только настройки.
- `navigator.storage.persist()` при первом запуске.
- Офлайн-fallback, все шрифты и иконки — локально.
- Проверять обновление по-настоящему: «обновление доступно → перезагрузить».

### 3.4 Техстек для v2 (предложение)
| Что | Предложение | Почему |
|---|---|---|
| Сборка | Vite + React + TS | то же, что сейчас, без боли |
| Анимация | CSS-анимации + `framer-motion` только в 2–3 местах (или `motion` с `LazyMotion`) | −100+ kB |
| Иконки | инлайновые SVG / эмодзи | убрать `phosphor-react` |
| Состояние | Zustand + persist в **IndexedDB** (через `idb`, уже в зависимостях) | надёжно, не вытесняется |
| Шрифт | системный (`system-ui`) или 1 локальный файл | офлайн + −сетевой запрос |
| Зависимости | удалить `howler`, `idb`→использовать, `react-router-dom` (не нужен) | чище и легче |
| PWA | `vite-plugin-pwa` (Workbox) вместо рукописного SW | precache, версии, офлайн-страница из коробки |

## Часть 4. Архитектура v2 (эскиз)

### 4.1 Контент: «урок», а не «сессия»
```ts
interface Word {
  id: string;
  text: string;              // «карандаш»
  stress: number;            // индекс ударной гласной
  syllables: string[];       // ['ка','ран','даш']
  danger: number[];          // индексы «опасных» букв → [3] (а в «к…рандаш»)
  dangerType: 'vowel' | 'consonant' | 'double' | 'softsign' | 'other';
  mnemonic?: string;         // «Карандаш — КАпает РАдуга на ДАШу»
  image: string;             // ключ картинки/эмодзи
  theme: string;             // «Школа» — тематический блок
  sentence: string;          // предложение с пропуском
  grade: number;
}

interface Lesson {           // урок = 6–8 слов одного тематического блока
  id: string; title: string; emoji: string;
  wordIds: string[]; order: number;
}
```
Плюс `LessonProgress { level: 0..5, lastDone, stars }` — уровень навыка (аналог корон Duolingo).

### 4.2 Структура урока (~10 заданий, 3–5 минут)
| # | Тип задания | Что тренирует |
|---|---|---|
| 1 | **Знакомство** (LOOK–SAY): слово целиком, ударение, слоги, озвучка, картинка, опасная буква «мигает» | формирование зрительного образа |
| 2 | **Орфо-чтение**: «повтори и проговори как пишется» + тап по слогам | слухо-речедвигательная память |
| 3 | **Окошко**: слово с пропущенной опасной буквой, выбрать из 2–4 | точное попадание в орфограмму |
| 4 | **Собери слово** из букв (есть подсказка) | порядок букв, моторика |
| 5 | **Диктант** (написать по слуху с клавиатуры приложения) | извлечение из памяти |
| 6 | **Найди ошибку** (слово написано неверно — исправь) | узнавание правильного образа |
| 7 | **Повторение слабых** слов урока + 1–2 слова из прошлых уроков (интерливинг) | перенос в долговременную память |
Отдельно: мини-игра на время (бонусный раунд) и «тренировка ошибок».

### 4.3 Разбор ошибки (обязательный такт)
Показать: верное слово крупно, **вашу и правильную букву рядом**, ударение, опасное место,
озвучка, короткая мнемоника → «напиши ещё раз правильно» → слово уходит в конец урока и в
«очередь ошибок» следующего дня.

### 4.4 Память (SRS) и мотивация
- SM-2 оставляем, но добавляем: отдельную очередь «ошибки дня», интерливинг (25% слов из
  прошлых уроков), ограничение «не больше N ошибок подряд без передышки».
- Ежедневная цель (регулируемая, по умолчанию 1 урок = ~4 минуты), серия дней + «заморозка»,
  XP, уровень профиля, 3 звезды за урок, достижения, магазин наград (на что тратить кристаллы —
  например, «раскраски/стикеры/новые эмоции БУКа»).
- Вибрация + звук + реакция маскота на каждое событие.

### 4.5 Слои кода
```
src/
  content/     — контент-пак: слова, уроки, мнемоника, картинки, (опционально) аудио
  engine/      — SRS, планировщик урока, подбор заданий, модель ошибок (без UI)
  platform/    — localStorage/IDB, TTS + fallback, звук, вибрация, PWA, версия данных
  ui/          — экраны и компоненты (mobile-first), дизайн-токены
  state/       — zustand-сторы
```
**Правило:** `engine` и `content` не знают про React — это позволит тестировать логику
обучения и потом переносить её (в т.ч. в нативное приложение).

## Часть 6. Критерии успеха (что измеряем)
1. **Возвращаемость**: доля дней с занятием за первые 14 дней, средняя длина серии.
2. **Завершаемость**: % уроков, доведённых до конца (сейчас легко бросить сессию).
3. **Качество**: % правильных ответов с первой попытки по новым словам; динамика по
   «ошибочным» словам через 1 / 3 / 7 дней.
4. **Технические**: старт офлайн < 1,5 с; установка на экран; работа без сети в «самолёте»;
   вес первого бандла ≤ 200 kB gzip.
5. **Полевое:** может ли ребёнок 7–8 лет пройти первый урок без помощи взрослого.
