3. Разработка UI/UX и Компонентов:

    Настройка темы:
        Реализовать контекст (React Context) для управления светлой/тёмной темой.
        Применить CSS Custom Properties (переменные) для цветов, определённых в ТЗ.
    Создание базовых компонентов:
        Button: Кнопка с анимацией Framer Motion, изменяющая стиль в зависимости от темы.
        InputField: Поле ввода слова с визуальной обратной связью (анимации Framer Motion) на правильность/неправильность. Поддержка изменения толщины шрифта.
        WordDisplay: Компонент для отображения слова, букв, с анимацией "вставания на место", дрожания, исчезновения.
        Navigation: Компонент навигации (например, между уровнями или упражнениями).
        UserProgress: Отображение прогресса пользователя (например, уровень, статистика).
        FocusMode: Компонент, реализующий режим фокуса (чистый экран, таймер).
        LevelCard: Карточка для выбора уровня (1-11 класс).
        ExerciseCard: Карточка для выбора типа упражнения (например, "Собери вещь", "Путешественник").
    Реализация анимаций:
        Использовать Framer Motion для всех микро-взаимодействий (ввод, ошибка, успех, переходы экранов).
        Добавить эффекты Glassmorphism при переходах (через стили и анимации Framer Motion).
        Внедрить тактильную обратную связь (Haptic Feedback) через API браузера/устройства, где возможно.
